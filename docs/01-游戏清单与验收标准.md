## 每款游戏统一验收标准（M1 起逐项打勾）

### A. 老年可用性（全部必须）
- [ ] 首次进入有「一屏大字图文说明」，之后可随时从顶栏"帮助"查看
- [ ] 正文文字 ≥ 20sp（随"超大字体"设置再放大 1.25×）
- [ ] 所有可点击目标 ≥ 64dp，有明显按压反馈
- [ ] 无倒计时/生命值/失败惩罚；随时可退，进度自动保存
- [ ] 支持 TalkBack 完整朗读（原生游戏逐控件；H5 游戏注入可访问标注）
- [ ] 横竖屏均可玩；退出有二次确认

### B. 产品红线（必须为真）
- [ ] 断网（飞行模式）可完整游玩
- [ ] 无任何广告、内购、登录、权限申请

### C. 技术（接入时检查）
- [ ] H5 游戏：WebView 配置 `blockNetworkLoads=true`、`allowFileAccess=false`（android_asset 不受影响）、`domStorageEnabled=true`
- [ ] 协议已登记 THIRD_PARTY_NOTICES.md（含改动清单）
- [ ] 打包体积增量可控（H5 游戏 ≤ 3MB/个，超出需瘦身）

### D. 试玩（M1 验收动作）
- [ ] 至少 3 位 60 岁以上真实用户试玩，填写《老年试玩问卷》（字号可读性/按钮好不好点/会不会玩/愿不愿意常玩）
- [ ] 中低端真机（4-8 年前机型）×2 + 开启系统大字体 ×1 各跑一轮
