# 03 · 老年友好设计规范（UI/UX 基线）

> 适用范围：外壳与**所有**游戏（含 H5 注入）。任何界面不满足本节即视为缺陷。
> 参考：适老化 9 原则（[uisdc](https://www.uisdc.com/group/612163.html)）、[中老服协适老化要点](https://www.siaa.org.cn/news_content?id=750)。

## §1 字号（三档全局设置，随系统字体缩放联动）

| 元素 | 标准 | 大 | 超大 |
|------|------|-----|------|
| 正文 | 20sp | 24sp | 30sp |
| 按钮文字 | 22sp | 26sp | 32sp |
| 标题 | 26sp | 30sp | 36sp |
| 游戏内数字/牌面 | 同正文档，H5 注入 `font-size` 放大系数 1.25×/1.6×/2.0× | | |

- 全局用 `sp`（跟随系统字体缩放）；H5 注入 CSS 用 `rem/em` 按根字号放大。
- 行高 ≥ 1.4；段落不缩进、不分栏。

## §2 触控目标与交互

- 最小可点击目标 **64dp**（高于 Android 48dp 基线）；卡片/按钮之间留 ≥ 12dp 间隙。
- 单击优先：不做双击/长按/边缘手势/滑动切换；滑动类游戏（2048）提供等价方向按钮。
- 按压反馈：颜色加深 + 轻微缩放动画（150ms）；动画可在设置中关闭（跟随系统"移除动画"）。
- 误触防护：返回/退出/清进度二次确认（大按钮弹窗）；游戏内提供"撤销"。

## §3 配色（高对比度友好）

| 模式 | 背景 | 前景/正文 | 主按钮 | 强调 |
|------|------|-----------|--------|------|
| 默认（暖色） | #FDF8F0 | #3B3B3B | #2E7D32（深绿）白字 | #E65100（橙） |
| 高对比度 | #000000 | #FFFFFF | #FFD600 黑字 | #FF6D00 |

- 正文对比度 ≥ 7:1；按钮文字 ≥ 4.5:1。
- 不使用纯红/纯绿区分状态（色盲友好），辅以符号（✓/✗/★）。

## §4 页面结构（外壳统一）

```
┌────────────────────────────┐
│  ← 返回（大）   标题（大）  │ ← 常驻顶栏，返回 ≥ 72dp
├────────────────────────────┤
│    （内容区，单列/宫格）     │
│                            │
│   [ 主要动作按钮 ≥ 64dp ]   │
└────────────────────────────┘
```

- 游戏顶栏固定：返回 + 标题 + [帮助] [字体] [音量] 四个大字按钮，全局一致。
- 图标必须配文字（老年用户对纯图标识别差）。

## §5 无障碍（TalkBack 等）

- 原生：所有可点击元素有可读文本/`contentDescription`；焦点顺序从左到右、从上到下；不拦截读屏手势。
- H5：注入 `role="button"` / `aria-label`；按钮使用真实 `<button>`；`<meta name="viewport">` 允许缩放。
- 游戏内"按钮操作模式"：每款游戏的所有操作都有等价屏幕按钮（默认开启）。
- 测试：TalkBack 全程可完成「进入游戏 → 玩一局 → 返回」。

## §6 内容与心理

- 零压力：无倒计时惩罚、无失败扣分、无体力/生命、无"再来一次"强制弹窗。
- 鼓励语言：完成对局显示"你真棒！"（可关闭音效）。
- 无任何付费/广告暗示文案。

## §7 验收用例（每个游戏跑一遍）

1. 系统字体调到"最大"→ 应用所有文字不截断、不错位。
2. 高对比度开启 → 所有界面可读。
3. TalkBack 开启 → 完成一局完整对局。
4. 误点返回 → 出现二次确认，选"继续玩"不丢失进度。
5. 飞行模式 → 全部游戏可玩。
