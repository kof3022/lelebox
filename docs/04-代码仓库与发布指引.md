# 04 · 代码仓库与发布指引

## 当前状态（M0）

- 本地 Git 仓库已在 `乐龄游戏盒/` 初始化，首次提交 `M0: 乐龄游戏盒立项`。
- 远程仓库尚未创建：本机到 github.com 直连被重置，需要按下面任一方案推流。

## 方案 A：本机可直连/有代理（推荐长期）

```bash
# 1. 在 GitHub 新建空仓库（如 lelebox/lelebox），不要勾选初始化 README
# 2. 关联并推送
cd 乐龄游戏盒
git remote add origin https://github.com/<你的账号>/lelebox.git
git branch -M main
git push -u origin main
```

> 若平时用代理：`git config --global http.proxy http://127.0.0.1:<端口>` 后再 push。

## 方案 B：暂以国内镜像托管（GitHub 不可达时）

- 先在 [Gitee](https://gitee.com) / [GitCode](https://gitcode.com) 建空仓库，然后：
  ```bash
  git remote add origin https://gitee.com/<账号>/lelebox.git
  git push -u origin main
  ```
- 之后可加 GitHub 为第二 remote（`git remote set-url --add --push origin <github>`），网络通时再同步。

## CI（GitHub Actions）

`android/.github/workflows/android-build.yml`（注意：文件在仓库根 `.github/workflows/`）：
- push/PR 自动 `assembleDebug` + `lint` + `testDebugUnitTest` + 上传 APK 产物 + `assembleRelease`。
- 首次推送后可在 Actions 页查看；国内 runner 拉依赖走 dl.google.com 通常可达。

## 版本与发布（M3 执行）

| 渠道 | 说明 |
|------|------|
| GitHub Releases | 上传 APK/AAB + 变更说明 |
| F-Droid | 走开源审核流程（需仓库 + 构建元数据 `fdroid` 目录） |
| 酷安 | 免费上架，需开发者认证 |
| 官网直链 | README 挂 APK 下载 |

## 签名（发布前必做）

- 生成 keystore 并妥善保管（**绝不提交仓库**）：
  ```bash
  keytool -genkeypair -v -keystore lelebox-release.keystore -alias lelebox -keyalg RSA -keysize 2048 -validity 10000
  ```
- release 构建签名方式在 M3 接入（当前 release 用 debug 签名占位）。
