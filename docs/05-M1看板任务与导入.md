# 05 · M1 看板任务与导入指南

> 任务看板（dsh-task-board）数据存于**浏览器 localStorage**（键 `dsh.taskBoard.v1`），Agent 无法直接写入浏览器存储，因此采用「控制台一键导入」。任务数据源文件：[m1-kanban-tasks.json](m1-kanban-tasks.json)（备份/审计用）。

## 导入步骤（一次性，约 30 秒）

1. 浏览器打开 DSH Web GUI：`http://127.0.0.1:3080`（就是你现在这个页面）。
2. 按 `F12` 打开开发者工具 → 切到 **Console** 标签。
3. 粘贴下方代码块，按回车。
4. 刷新页面（`F5`）。
5. 侧边栏「任务看板」出现 **12 张 M1 卡片**（6 待办 + 6 待规划）。

> 导入采用**按 id 合并**：已有任务保持不变，仅追加缺失的 M1 卡片，可安全重复执行。

## 说明

- **为什么不用 workspaceId 预置**：运行时工作区 id 由 DSH 提供（`workspaces.list`），Agent 侧无法枚举；导入后可在卡片详情下拉把「工作区」钉到 `乐龄游戏盒` 目录，执行时会自动连接该工作区。
- 卡片执行（点「运行」）会驱动一个 agent 会话，按卡内 prompt 自包含执行；权限已预置 `workspace-write`（写代码任务）或 `read-only`（审计/测试任务）。
- 12 张卡与 [docs/01-游戏清单与验收标准.md](01-游戏清单与验收标准.md) 的 M1 范围一一对应。
