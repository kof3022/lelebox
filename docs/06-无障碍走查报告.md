## §0 模拟器无障碍树审计结果（2025-08，AVD Pixel_API_36）

方法：逐游戏进入 → uiautomator 导出无障碍树 → **树遍历**检查「可点节点自身或其任意后代均无文本/描述」的数量。

| 界面 | 可点节点数 | 真正无标签 | 结论 |
|------|-----------|-----------|------|
| 首页 | 5（卡片×4+设置） | 0 | ✅ |
| 2048 | 7（返回/帮助/重开/方向×4） | 0 | ✅ |
| 纸牌接龙（H5） | 19（发牌/废牌/收牌×4/桌牌×7/牌面/按钮×4） | 0 | ✅（aria-label 全覆盖） |
| 数独 | 96（81 格+操作/数字键） | 0 | ✅ |
| 记忆翻牌 | ≥4（当前截取树） | 0 | ✅（每卡含 contentDescription） |

> 说明：Compose `Button` 的文本标签位于其子节点（uiautomator 父节点 text 为空属正常合并语义），故采用**子树遍历**口径；本轮已移除 ElderButton 上冗余的 `contentDescription`（避免 TalkBack 重复朗读）。

## §0 真机读屏走查结果（2025-08，HUAWEI LIO-AN00 / P30 Pro）

设备：华为 P30 Pro（EMUI）。读屏服务：`com.bjbyhd.screenreader_huawei/.ScreenReaderService`（第三方中文屏幕朗读，TalkBack 同功能：SPOKEN+HAPTIC+AUDIBLE 反馈、触控探索）。
方法：`settings put secure` 临时启用读屏 → uiautomator 树 + **双击进入 + TAB 焦点遍历** → 走查后恢复原设置（已还原）。

| 游戏 | 读屏下进入 | TAB 焦点顺序（前 3-4 步） | 结论 |
|------|-----------|--------------------------|------|
| 2048 | ✅ 双击卡片进入 | ←返回 → 帮助 → 重新开始 → ↑方向键 | 焦点序与视觉布局一致 |
| 纸牌接龙（H5） | ✅ 双击进入 | ←返回 → 帮助 → **撤销**（H5 按钮带标签可聚焦） | WebView 无障碍在真机可用 |
| 数独 | ✅ 双击进入+选难度 | ←返回 → 帮助 → 重新开始 | 棋盘可达 |
| 记忆翻牌 | ✅ 双击进入+选难度 | ←返回 → 帮助 → 第一张牌 | 棋盘可达 |

> 全部走查完成后已**将手机无障碍设置恢复原状**（读屏关闭）。
