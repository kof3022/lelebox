# 09 · 游戏图标设计 · 即梦（Jimeng）提示词

> 目标：四款游戏图标 + 启动图标，风格统一为「乐龄游戏盒」的 **Editorial Luxury 暖调**：
> 暖奶油底、圆润友好、扁平插画质感、无文字、适合大字卡片场景。生成的 PNG 替换矢量占位图即可上线。

## 统一风格前缀（每张都带）

```
扁平插画图标，暖奶油色背景（#FBF7F0），主体居中，圆角方形卡片构图，
柔和暖色阴影，editorial luxury 质感，干净精致，无文字，无边框文字，
主体用单一强调色 + 白色点缀，适合老年人应用的清新友好风格，高清矢量感
```

## 1. 2048（青绿 #3E8E7E）

```
一组正在合并滑动的数字方块，三个圆角方块从上到下逐渐变小叠加，
最下方方块与中间方块之间有一条微微靠近的动感间隙（表示合并），
青绿色 #3E8E7E 方块 + 白色圆角小方块点缀，极简，无数字文字
```

## 2. 纸牌接龙（陶土 #C4623C）

```
两张白色扑克牌一前一后微微错开成扇形，牌面点缀陶土色 #C4623C 的
圆角小方块图案（如两个小圆点），牌背朝后的那张透出一点陶土色边缘，
温馨怀旧感，极简扁平
```

## 3. 数独（雾蓝 #4A6FA5）

```
一个 3x3 的九宫格小方块阵列，九个圆角小方块大部分为雾蓝色 #4A6FA5，
中心一格反白描边（表示待填），排列整齐、留白充足，极简益智感
```

## 4. 记忆翻牌（灰紫 #7A5C9E）

```
两张并排的白色翻牌卡片，左边卡面有一个灰紫色 #7A5C9E 实心圆，
右边卡面有一个同色圆环（配对目标），两张卡微微分开、边缘有暖色细线，
可爱轻松，极简扁平
```

## 5. 应用启动图标（2025-08 重设计）

```
一枚温暖的小游戏机图标：鼠尾草绿（#3D6B52）大圆角方形底，
中央一个奶油白色（#FBF7F0）的圆润游戏手柄，手柄左右各一个圆润按键，
手柄下方一条淡淡的暖奶油弧线（似笑脸），四周留白充足，
扁平插画，柔和暖色阴影，editorial luxury 质感，无文字，无边框，正方形构图
```

## 生成与替换步骤

1. 在「即梦」粘贴上面提示词（建议 1:1，输出 1024×1024），挑一张满意的。
2. 用工具裁成正方形、去背景（如无需背景则保留暖奶油底）。
3. 放入 `android/app/src/main/res/drawable-xxhdpi/`（或 mipmap 系）：
   - `ic_game_2048.png` / `ic_game_solitaire.png` / `ic_game_sudoku.png` / `ic_game_memory.png`
   - 启动图标：替换 `mipmap-*/ic_launcher*.png` 与 `drawable/ic_launcher_foreground.xml` 对应内容。
4. `Games.kt` 中 `iconRes` 指向的资源名保持不变，PNG 同名即可覆盖矢量占位图。
5. 重新 `assembleDebug` 打包验证。

> 当前已内置同风格的**矢量占位图标**（`res/drawable/ic_game_*.xml`），即梦图生成前 UI 已是统一风格。
