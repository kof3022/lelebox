# 10 · 记忆翻牌 · 动物头像即梦提示词

> 目标：8 种常见动物的**统一风格头像**，用于记忆翻牌卡面。生成后放入
> `android/app/src/main/res/drawable-xxhdpi/ic_animal_<id>.png` 并在
> `MemoryAnimals.kt` 对应条目填 `iconRes`，即可覆盖 emoji 显示（TalkBack 仍朗读动物名）。

## 统一风格前缀（每张都带，只改动物）

```
温暖扁平插画动物头像，正脸居中，圆脸大头可爱风格，暖奶油色背景（#FBF7F0），
柔和的暖色阴影，editorial luxury 质感，线条圆润简洁，无文字，无边框，
适合老年人休闲游戏的清新友好卡面，单一主色点缀，高清矢量感，正方形构图
```

## 8 种动物提示词

| id | 动物 | 提示词主体 |
|----|------|-----------|
| cat | 小猫 | 一只橘色小猫头像，圆脸大眼睛，胡须清晰，耳朵尖尖 |
| dog | 小狗 | 一只米色小狗头像，圆脸耷拉耳朵，黑色圆鼻头，吐一点舌头 |
| rabbit | 兔子 | 一只白色兔子头像，长耳朵立起，粉色内耳，三瓣嘴 |
| panda | 熊猫 | 一只熊猫头像，黑白配色，黑眼圈圆润，抱竹叶微笑 |
| frog | 青蛙 | 一只绿色青蛙头像，大眼睛圆鼓鼓，嘴角上扬，两颊微红 |
| monkey | 猴子 | 一只棕色小猴头像，圆脸圆耳，头顶一撮毛，表情俏皮 |
| bear | 小熊 | 一只浅棕色小熊头像，圆耳朵，鼻头深棕，表情憨厚 |
| fox | 狐狸 | 一只橙红色狐狸头像，尖耳三角脸，白色口鼻，眼神机灵 |

## 生成与替换

1. 即梦粘贴「统一前缀 + 对应动物」，1:1 输出 1024×1024。
2. 裁切为正方形（如需去背景，保留暖奶油底即可与卡面协调）。
3. 命名放入 `res/drawable-xxhdpi/`：`ic_animal_cat.png`、`ic_animal_dog.png` … `ic_animal_fox.png`。
4. 在 `MemoryAnimals.kt` 对应条目填 `iconRes = R.drawable.ic_animal_cat` 等。
5. 重新打包验证；8 张齐后「困难（8 对）」牌面即为统一风格动物头像。
