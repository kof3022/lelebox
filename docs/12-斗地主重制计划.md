# 12 · 斗地主重制计划（对照欢乐斗地主对局界面）

> 说明：本网络无法直接抓取欢乐斗地主截图（尝试 apkpure / 豌豆荚 / 233 乐园 / 百科等均被墙、404 或 403，仅能取到站内装饰图）。
> 以下分析基于该游戏**公认的对局界面构成**（国民级游戏，界面模式稳定）与现有实现差距，如需可后续补充官方截图核对细节。

## 一、欢乐斗地主对局界面构成（参考目标）

### 1. 桌面中央（出牌区）
- 三家出的牌**集中展示在桌面中央**：每一家出的牌一组（横排小卡，可扇形），上方/左侧标注「上家 / 你 / 下家」与"不出"。
- **底牌 3 张**：叫地主后亮在桌面中间顶部（地主拿底牌前先展示）。
- 一轮结束（两过）清空桌面，重新自由出牌。

### 2. 对手区（横屏时左右两侧/上角）
- 对手：**头像 + 昵称 + 剩余张数**（牌背小图标）+ **身份徽章**（地主皇冠 / 农民）。
- 出牌/过牌/要不起的**即时反馈**（气泡或动效）。

### 3. 手牌区（底部）
- 自己全部牌**扇形/弧形排列**（中心牌最高、两侧微旋下沉），视觉上"握在手里"。
- 点选牌**浮起高亮**；可整体排序（升序、按牌型分组）。
- 底部操作栏：**出牌 / 不出 / 提示 / 托管**，以及叫地主、抢地主、加倍等流程按钮。

### 4. 流程与反馈
- 叫地主/抢地主 → 亮底牌 → 出牌（欢乐带出牌倒计时，**老年版去掉倒计时**）→ 结算（胜负 + 简单统计）。
- 音效/动画（出牌飞入、扇形展开、胜利欢呼）。

## 二、差距分析（当前实现 vs 目标）

| 维度 | 当前（v0.3.5） | 目标（对照欢乐） | 差距 |
|---|---|---|---|
| 屏幕方向 | 竖屏 | **横屏为主**（本次要求） | 需新增横屏布局 |
| 出牌区 | 左侧文字列表（谁+牌型文字） | **中央桌面三组卡片展示** | 大 |
| 手牌 | 平铺横滑、点选 | **扇形弧形排列** + 浮起高亮 | 中 |
| 对手呈现 | 小面板（名字+张数+身份文字） | 头像+张数+身份徽章+即时反馈 | 中 |
| 底牌 | 叫地主时小卡展示 | 桌面顶部亮底牌 | 小 |
| 流程 | 叫地主→出牌→结算 | 叫地主/抢地主→亮底牌→出牌→结算（老年版不加减倍） | 中 |
| AI | 基础启发式 | 记牌/强度分层（简单/普通/困难） | 中 |
| 托管 | 无 | 托管按钮（AI 代出当前手） | 小 |
| 动画/音效 | 基础音效 | 出牌飞入/扇形/胜利动效 | 中 |

## 三、开发计划（P1 横屏优先，共约 5–7 天）

> **已完成（v0.4.0）**：P1 横屏（斗地主强制横屏，其余保持竖屏）；P2 中央桌面（牌桌绿底 + 底牌顶部 + 三家出牌卡：电脑1左上/电脑2右上/你中下）；P3 手牌扇形（微旋排列 + 选牌浮起）；P4 身份徽章（地主金/农民绿）+ 头像占位（👴👵，即梦后补）+ 托管按钮；P5 选难度（简单/普通/困难，AI 分层：简单常留牌、困难对手快赢才炸）+ 叫地主流程 + 结算页；P6 胜利音效 + 扇形旋转（出牌飞入动画待后续打磨）。真机横屏验证通过。
>
> **v0.4.1（本轮）**：斗地主玩牌沉浸全屏——隐藏系统状态栏/导航栏与游戏壳顶栏（ElderTopBar），界面内自带紧凑「← 返回」「帮助」按钮（44dp 无障碍基线）；难度选择页也带「←」返回。真机（P30 Pro）验证：mCurrentRotation=ROTATION_90、无系统栏、无游戏壳顶栏、帮助弹窗与返回均正常。版本 0.4.1-m1（versionCode 17）。
>
> **v0.4.2（本轮）**：① **牌桌全屏显示**——整屏深绿绒布渐变 + 金色包边，中央桌面透明化；即梦牌桌背景图提示词见 `docs/13`（可选接入）。② **先发牌后叫地主**——进入对局自动发牌，叫地主阶段即可看到自己的手牌与对手手里的牌背（层叠显示、随出牌实时减少）；**底牌叫地主前扣着看不到**（3 张牌背 + "底牌已扣，叫地主后翻开"），叫地主后翻开并插入地主手牌（20 张）。修复：`DoudizhuGame` 进入时未自动 `newDeal()` 导致发牌缺失的隐藏 bug；压缩对手面板/状态行/手牌区布局，横屏下对手面板（头像/徽章/牌背/剩余张数）完整显示不裁剪。版本 0.4.2-m1（versionCode 18）。
>
> **v0.4.3（本轮）**：① AI 对手命名**孔子**（电脑1）/ **庄子**（电脑2），即梦头像提示词见 `docs/14`；② 身份徽章移到头像**同一行**（头像右侧），面板高度进一步缩减；③ 桌面出牌区**去掉**"电脑1/电脑2/你"标签，出牌放大展示（40×56dp），本轮"过"显示灰字"过"，轮到玩家显示黄色"请出牌"，默认留空（去掉横杠）；④ **一局打完在桌面中央显示特殊颜色胜负横幅**——赢=金色（🎉 你赢啦！），输=红色（😊 地主赢了/农民赢了），半透明遮罩 + 再来一局/换难度按钮。修复：结算遮罩移入牌桌 Box 内并用 `key(tick)` 包裹，保证 `game.over` 时强制重组显示。版本 0.4.3-m1（versionCode 19）。

### P1 横屏支持 + 布局重排（0.5–1 天）
- `GameShellActivity` 按 `game.id` 设置方向：斗地主横屏、其余竖屏（`requestedOrientation` 动态切换，退出恢复）。
- 横屏布局：左对手区（左上）· 右对手区（右上）· 桌面居中 · 手牌底部弧形。

### P2 中央桌面出牌区（1 天）
- 桌面中央三组出牌卡（各家 `lastPlays` 大卡横排展示，扇形可选）；「不出」显示；底牌顶部展示；回合指示（当前行动者高亮）。

### P3 手牌扇形 + 排序（1–1.5 天）
- Canvas 弧形排列手牌（中心最高、两侧旋转下沉），点选浮起；排序优化（升序/按牌型）。
- 横屏下扇面更大，点击区按视觉位置对齐（避免此前 offset 错位问题）。

### P4 身份/信息/托管（0.5–1 天）
- 地主/农民徽章（皇冠/麦穗图标，矢量）；对手头像（**即梦生成 3 个温和老年头像**，先矢量占位）；剩余张数。
- **托管**按钮：AI 代出当前手（复用 `aiLead/aiFollow`），再点取消。

### P5 AI 与流程完善（1–2 天）
- AI 记牌/强度分层（简单=随机偏弱、普通=当前启发式、困难=记牌+拆牌优先）；「重新发牌→选难度」入口。
- 流程：叫地主/不叫 → 亮底牌 → 出牌 → 结算页（欢乐风格：胜负 + 简单统计 + 再来一局）。

### P6 打磨（1 天）
- 出牌飞入/扇形展开动画（transform/opacity）、胜利音效、横屏无障碍与字体适配、真机验证。
