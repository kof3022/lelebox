# 13 · 斗地主牌桌背景（即梦提示词）

> 状态：**当前用 Compose 纯色渐变实现全屏牌桌（深绿绒布渐变 + 金色包边），无需图片即可运行**。
> 如需更精致的真实牌桌质感，用下面的提示词在即梦生成，再按 `docs/09` 的素材管线接入。

## 一、需求说明（v0.4.2）

1. **全屏牌桌**：斗地主对局时，深绿牌桌铺满整个屏幕（横屏），不再是小块中央桌面。
2. **即梦生成（可选）**：一张横屏 2:1（手机横屏比例，约 2400×1176）的牌桌背景图：
   - 深墨绿色绒布/毡面质感，细腻布料纹理
   - 桌面中央微微提亮（模拟顶部灯光），四周渐暗收边
   - 中央可以有低调的浅金花纹或圆环装饰（不要太花，老年用户要看得清牌）
   - **不要**：任何文字、任何扑克牌、任何人物、任何 UI 图标、边角品牌 Logo
3. 接入后代码里用 `painterResource` 替换当前渐变背景，并叠一层半透明深绿保证牌面对比度。

## 二、即梦提示词（可直接复制）

### 正向提示词
```
横屏扑克牌桌背景图，2:1 比例。深墨绿色丝绒毡布桌面，细腻的绒布质感与
自然褶皱纹理。桌面中央有一圈低调的浅金色细纹圆环装饰，中央微微提亮如
灯光照射，四周边角渐暗。整体色调沉稳温暖，高端棋牌室氛围。画面干净
简洁，留出大片平整桌面空间，方便在上面放置扑克牌。无任何文字，无任
何扑克牌，无人物，无 UI 元素，无 logo。写实风格，高清细节。
```

### 反向提示词
```
文字, 水印, logo, 扑克牌, 人物, 手, 手机, 界面, 按钮, 图标, 边框, 卡通
```

### 出图参数建议
- 比例：**2:1**（或 16:9 裁切到 2:1），分辨率越高越好（≥2K）
- 数量：生成 3~4 张选一张纹理均匀、中间干净、边缘不裁人物的
- 风格：写实 / 摄影质感，不要插画卡通

## 三、接入步骤（素材到位后）

1. 把选好的 PNG 放到 `乐龄素材/`（仓库外的素材目录），命名 `table_felt.png`
2. 运行 `scripts/generate_icons.ps1` 或同款缩放脚本，生成
   `res/drawable-xxhdpi/table_felt.png` 与 `res/drawable-xxxhdpi/table_felt.png`
3. `DoudizhuScreen.kt` 全屏牌桌背景改为：
   ```kotlin
   .background(painterResource(R.drawable.table_felt), ...)
   ```
   并在图片上叠一层半透明深绿（`Color(0x66000000)`）保证白牌对比度
4. 真机（P30 Pro 横屏）验证：文字、按钮、牌面在图片上清晰可读

## 四、当前实现（无需图片）

- 背景：`Brush.verticalGradient(0xFF1E3B2E → 0xFF2C4A3B → 0xFF163024)`
- 包边：3dp 金色圆角边框 `0xFFC9A24B`
- 状态行/叫地主行：半透明深色条（`0x99000000` / `0x66000000`）保证可读
- 中央出牌区：透明（牌桌即全屏背景）
