# 15 · 找不同 9 张场景底图（即梦提示词）

> 状态：**9 张底图已接入（v0.4.14）**——即梦生成 → `generate_spot_assets.ps1` 缩放 → PNG 转 JPEG(质量82) 控体积 → `SpotSceneDef.bgRes` 引用；差异小元素仍由程序绘制（坐标可单测，玩法不变）。

## 一、核心思路（重要）

找不同 = **同一场景的两幅图 + 差异掩码**（参考开源项目如 [zukahai/spot-the-difference-game](https://github.com/zukahai/spot-the-difference-game)）。

- **底图**：即梦生成 9 张**竖构图生活场景空景**（天空/地面/建筑/植被等大块面），**不要包含任何小装饰**（云/太阳/鸟/花/果实/动物/气球/风筝/灯等）——这些是"差异小元素"，继续由**程序绘制**，保证：
  1. 两幅图差异位置精确可定位（点击判定、单测不变）
  2. 程序可控制"有/无、颜色 A/B"两种变体
- 所以提示词必须强调「画面干净、留白、无小物件」。

## 二、通用提示词模板

### 正向（每场景替换 [场景描述]）
```
儿童绘本插画风格，温暖明亮的[场景]，扁平卡通，构图简洁，大块面纯色，
画面干净整洁，留白充足。天空/背景平整干净，**不要出现任何云朵、太阳、
飞鸟、花朵、果实、动物、气球、风筝、灯具、玩具等小物件**。柔和平滑的
渐变背景色，无文字，无边框。竖构图 3:4。
```

### 反向（全部场景统一）
```
云, 太阳, 鸟, 花, 果实, 苹果, 动物, 猫, 鸭子, 气球, 风筝, 灯, 星星,
月亮, 雪人, 玩具, 文字, 水印, logo, 边框, 人物, 手, 卡通描边, 阴影过重
```

## 四、出图参数建议

- 比例：**3:4 竖构图**（找不同为上下两幅竖长图）
- 数量：每场景生成 2~3 张，选「构图简洁、留白充足、无小物件」的一张
- 风格：保持全部 9 张**同一绘本风格**（同一风格词开头，画面才统一）

## 五、接入步骤（素材到位后）

1. 9 张 PNG 放 `乐龄素材/`，命名：`spot_garden.png`、`spot_living.png`、`spot_orchard.png`、`spot_park.png`、`spot_seaside.png`、`spot_farm.png`、`spot_snow.png`、`spot_street.png`、`spot_night.png`
2. 运行 `scripts/generate_spot_assets.ps1`（自动缩放到 `drawable-xxhdpi/xxxhdpi/spot_*.png`）
3. `SpotScene.kt` 每个场景定义加底图字段（`bgRes` 已预留在 `SpotSceneDef`，`ScenePanel` 已支持"底图 + 差异层"叠加）：
   ```kotlin
   val SCENE_GARDEN = SpotSceneDef(name = "花园", diffs = GARDEN_DIFFS, draw = { drawGarden(it) }, bgRes = R.drawable.spot_garden)
   ```
   `drawGarden` 等绘制函数可只保留**差异小元素**（去掉大块面底/天空/山丘），避免与底图重复。
4. 真机验证：9 关点击命中、上下图差异可见、无重叠错位
