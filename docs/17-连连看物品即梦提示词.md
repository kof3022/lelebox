# 17 · 连连看物品即梦提示词

> **已接入（v0.5.5）**：按下方提示词生成的 8 张水果图已由用户放入「乐龄素材」目录，压缩为 512×512 PNG 接入 `res/drawable-xxhdpi/link_*.png`，牌面从 emoji 换为图片（无障碍语义用中文水果名）。

> 用途：连连看棋盘上的**牌面图案**（当前为 emoji 🍎🍊🍇🍓🍑🍒🍋🍉，可换为即梦生成的统一风格水果图标）。
> 生成后裁切为**正方形**，建议 512×512 以上，浅色圆角底（近似牌面）；接入时放 `res/drawable-xxhdpi` 等并命名 `link_apple / link_orange / link_grape / link_strawberry / link_peach / link_cherry / link_lemon / link_watermelon`。
> 风格要求：**统一**（同一批生成，同光源同角度）、**颜色鲜明**（老年友好，辨识度高）、**扁平插画风**、无文字、无阴影外装饰、纯白或米白背景。
